# SkillBridge ⚡

**Connecting Skilled Students with Clients**

SkillBridge is a modern, responsive, full-stack marketplace where students showcase their skills and clients hire them for affordable services. Built with Django, Bootstrap 5 and a premium startup-grade UI (glassmorphism, dark/light mode, smooth animations).

---

## ✨ Features

### Authentication
- Register / Login (username **or** email) / Logout
- Forgot-password with emailed reset links (console backend in dev)
- Role selection: **Student (provider)** or **Client**
- Provider accounts require admin approval before listing services

### Marketplace
- Landing page with hero, live stats, featured services, top providers, testimonials, FAQ and contact form
- Browse services with **live JavaScript search** (skill, name, category, price)
- Filters: category, price range, rating, availability + sorting (newest, price, top rated, most booked)
- Provider public profiles: photo, bio, skills, ratings, reviews, completed jobs
- Wishlist (save services)

### CRUD
- **Services** — create, read, update, delete (provider only, role-guarded)
- **Bookings** — request, view, update status (Pending → Accepted → Completed / Cancelled), cancel, delete
- **Reviews** — create, edit, delete with 1–5 star ratings

### Dashboard (role-aware)
- Analytics: services, bookings, completed jobs, pending, average rating, revenue
- 7-day bookings chart + category breakdown (Chart.js)
- Profile completion ring & checklist, recent bookings/services, quick actions

### Notifications
- In-app bell with unread badge for new bookings, accepted/cancelled bookings, new reviews

### JavaScript & UI
- Dark mode toggle (persisted), toast notifications, live search, animated counters, scroll reveal, button ripple, password strength meter, character counters, image previews, star-rating picker, confirm-delete modals, skeleton loaders, mobile offcanvas menu

### Admin (Django Admin)
- Manage users, approve providers, approve/hide services, delete reviews, view bookings

## 🚀 Getting Started

```bash
# 1. Clone & enter the project
git clone <repo-url> skillbridge
cd skillbridge

# 2. Create & activate a virtual environment
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS/Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Migrate the database
python manage.py migrate

# 5. Seed demo data (categories, providers, clients, services, bookings)
python manage.py seed_demo

# 6. Run the server
python manage.py runserver
```

Open **http://127.0.0.1:8000** 🎉

## ☁️ Deploying to AWS

Settings read environment variables so deployment is straightforward:

- `DJANGO_SECRET_KEY` — set a strong secret
- `DJANGO_DEBUG` — `False` in production
- `DJANGO_ALLOWED_HOSTS` — comma-separated hostnames
- `DATABASE_URL` — e.g. `postgres://user:pass@host:5432/dbname`
- `EMAIL_BACKEND` / `EMAIL_HOST*` — SMTP (e.g. AWS SES)

Then:

```bash
python manage.py collectstatic --noinput
gunicorn config.wsgi:application
```
